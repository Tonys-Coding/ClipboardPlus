# Clipboard+ v1.8.5 — Clearer Code classification

Clipboard+ now requires stronger syntax before placing copied content in **Code**. Ordinary prose that mentions words such as “function,” “return,” or “if,” or contains brackets and inline markup, stays in **Text**. Recognizable declarations, complete JSON and markup, structured SQL/CSS, shell commands, and code fences still enter **Code**.

On first launch after updating, existing clips are reclassified once. Clip content, favorite status, source information, and timestamps are preserved. Classification remains intentionally conservative: some ambiguous short code may remain in Text rather than sending ordinary text to Code.

The original v1.8.4 small and marquee promotional tiles and their generator are restored. Capture permissions, local-only storage, and the native messaging contract are unchanged. All current features remain free.

`clipboard-plus-v1.8.5-store.zip` is the matching Chrome Web Store package. GitHub publication does not update the Chrome Web Store automatically; submit the ZIP there separately.
