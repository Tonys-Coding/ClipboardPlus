# Clipboard+ v1.8.3 — A clearer Workspace

This release gives the Chrome popup, Capture Controls, and public website a more cohesive, content-first design. The official Clipboard+ logo remains, while bundled Hanken Grotesk provides the web interface typography. The macOS companion retains its current native look.

- The popup has distinct navigation, recent results, and full-content preview panes. Clicking a clip still copies it immediately, and favorites remain exclusively in Saved.
- A rounded popup frame and a locally stored light/dark switch apply to the popup and Capture Controls. The public website has its own browser-local appearance preference.
- Capture Controls no longer follows the pointer with a spotlight. A consistent Lucide line-icon set identifies capture categories and page actions; the existing clipboard artwork stays at the sides of wide layouts.
- Five Chrome Web Store screenshots and both promotional tiles now show the current interface. The public website's preview is generated from the actual popup build.
- The popup's initial fixed size prevents Chrome from displaying it as a narrow strip while measuring the action window.

The free core remains free. This release adds no permissions, accounts, analytics, billing, or remote clipboard processing. The store profile continues to exclude the developer-preview macOS companion.

`clipboard-plus-v1.8.3-store.zip` is the matching Chrome Web Store upload package. Publishing this GitHub release and the GitHub Pages website does not automatically update the Chrome Web Store listing; that package must be submitted separately.
