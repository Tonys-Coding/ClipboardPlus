# Clipboard+ v1.8.4 — A consistent icon language

The Chrome Workspace now uses the requested Lucide icons: Playing Cards Fan for All, Save for Saved, Pencil Ruler for Text, Link 2 for Links, and Code XML for Code. The Text, Links, and Code icons match across navigation, clip rows, previews, and Capture Controls. The official Clipboard+ logo is unchanged.

The public website previews, five Chrome Web Store screenshots, and two promotional tiles have been regenerated from the current build. No capture behavior, permissions, data handling, or native companion behavior changed.

All existing features remain free and local. `clipboard-plus-v1.8.4-store.zip` is the matching Chrome Web Store upload package. This GitHub release and the GitHub Pages update do not automatically update the Chrome Web Store listing; the package must be submitted separately.
