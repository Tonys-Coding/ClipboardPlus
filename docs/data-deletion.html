Delete your data

Clipboard+ stores Chrome history on your device, so no account request is necessary.

Use automatic cleanup

Open Clipboard+ Settings and choose a retention period. Expired non-favorite clips are removed locally; favorites never expire automatically.

Clear recent history

Open Clipboard+ Settings and select Clear history. Non-favorite clips are deleted; favorites remain.

Clear everything

Open Clipboard+ Settings, select Clear all data, and confirm. All clips and favorites are deleted from extension storage.

Remove website access

Turn Automatic web capture off in Clipboard+ Settings. The extension removes its optional access to ordinary websites.

Remove the extension

Open chrome://extensions, find Clipboard+, and select Remove. Chrome deletes the extension's local storage as part of removal.

Clear the website appearance choice

The public website remembers only its light/dark choice in browser local storage. Clear site data for tonys-coding.github.io in your browser to remove that preference; this does not change the extension's saved clips.

Contact support if these controls do not work as described.
