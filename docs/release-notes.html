Release notes

Everything in these releases is part of the permanent free core. No account, analytics, advertising, or cloud service is required.

1.8.0

Accessibility, undo, preview, and honest capture feedback.

  • Open Clipboard+ with the suggested Alt+Shift+C shortcut (reassignable in Chrome), focus search automatically, and move through favorites and recent clips with the arrow, Home, and End keys.
  • Undo an individual clip deletion for eight seconds. Clearing history or all data stays confirmed and irreversible.
  • Preview a full clip in a read-only dialog that keeps its whitespace, type, size, and source details, without opening links.
  • Copy a smart snippet's stored text directly with Copy original, skipping fill-in fields and transformations.
  • Clear capture notices distinguish checking, paused, excluded, restricted browser pages, missing website access, disabled capture, and unreachable listeners, with relevant recovery controls. Pauses remain resumable on restricted or excluded pages.
  • Shared keyboard and focus behavior across the edit, preview, snippet, and transformation dialogs and the clip menus, plus copy announcements for screen readers.
  • An About & help section with the runtime version, the current shortcut, release notes, support, and a redacted troubleshooting copy that never includes clipboard contents, page addresses, excluded domains, or identifiers.

1.7.1

  • Activate automatic capture immediately in eligible website tabs that were already open when access was enabled or Clipboard+ was updated.
  • Continue past restricted or unavailable tabs without interrupting capture elsewhere.

1.7.0

  • Optional automatic cleanup after 24 hours, 7 days, 30 days, or 90 days, always preserving favorites.
  • Independent automatic-capture controls for text, links, and recognizable code.
  • Temporary privacy pauses, an indefinite pause, and a one-hour quick pause in the popup.
  • Optional source details, a local storage overview, and cleanup actions.

Earlier releases

  • 1.6.1 — first-run disclosure and affirmative consent before automatic website capture, with website access moved to optional permissions.
  • 1.6.0 — reusable smart snippets with {{field}} placeholders and local paste transformations.
  • 1.5.4 — the bundled Satoshi variable font across the popup and settings page.

Release notes summarize the free changes in each version. Privacy details stay in the privacy policy, and help is on the support page.
