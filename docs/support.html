Clipboard+ Support

Help with website capture, saved clips, privacy controls, and the Chrome Web Store release.

Website copies are not appearing

  1. Open Clipboard+ Settings.
  2. Turn on Automatic web capture and approve website access.
  3. Resume capture if a privacy pause is active.
  4. Confirm the copied content category is enabled.
  5. Refresh pages that were already open.
  6. Confirm the current domain is not in Excluded sites.

Chrome settings, the Chrome Web Store, New Tab, the address bar, and other browser-owned pages cannot be captured. Use Add clip or Save tab when appropriate.

Clipboard access was blocked

Open the extension popup directly and click the clip again. Chrome requires a user action before an extension can write to the clipboard.

Keyboard shortcut

Clipboard+ suggests Alt+Shift+C to open the popup with search focused. It is a browser-only shortcut: it works while Chrome is in front and does nothing in other applications. Reassign or clear it on Chrome's Manage extension shortcuts page (chrome://extensions/shortcuts); Chrome leaves the suggestion unassigned when another extension already uses that combination. Inside the popup, the Down arrow moves from search into your clips, Up and Down move between rows, Home and End jump to the ends, Enter copies the focused clip, and Escape returns to search.

Light and dark appearance

Use the moon or sun button in the popup, or choose Appearance in Capture Controls. That choice is saved locally and applies to both extension pages. The public website has its own theme switch in the navigation; its choice is stored separately by your browser.

Capture limits

Automatic capture is off until you enable it. Even when it is on, Chrome internal pages, the address bar, New Tab, Chrome settings, the Chrome Web Store, and other browser-owned pages cannot be captured, and password fields plus recognized authentication and payment fields are always ignored. The popup reports the exact reason capture is inactive on the current tab — off, missing permission, excluded site, restricted page, pause, or unreachable listener — and offers the matching action. Deleting a single clip can be undone for eight seconds; clearing history or all data cannot.

Troubleshooting details

Settings → About & help can copy a short local checklist with your Clipboard+ version, build profile, capture settings, website-access status, and listener health. It never includes clip contents, page addresses, excluded domains, or identifiers, and Clipboard+ never sends it anywhere.

Delete data

Open Settings to review local storage, set automatic cleanup, clear non-favorite history, or delete all locally stored data. Full removal instructions are available on the data deletion page.

Report a problem

Use the Support hub on the Clipboard+ Chrome Web Store listing. Open Settings → About & help and choose Copy troubleshooting details to attach a short checklist with your version, capture settings, website-access status, and listener health. Do not include private clipboard contents, passwords, authentication codes, or payment information in a support request. Current and recent changes are summarised in the release notes.
