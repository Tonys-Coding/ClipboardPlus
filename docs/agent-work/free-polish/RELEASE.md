# Clipboard+ v1.8.0 — Free polish

Seven improvements to the permanent free core:

- Open the Chrome popup with Alt+Shift+C (customizable), search immediately, navigate clips with arrow keys, and press Enter to copy.
- Undo individual deletions for eight seconds.
- Preview full clips with preserved whitespace and source details.
- Copy a snippet's original text without filling its placeholders.
- Clearer capture/loading failures, recovery actions, and timed-pause feedback.
- Keyboard-friendly menus and dialogs, focus restoration, and copy announcements.
- About & help with the current shortcut, version, public support/release notes, and privacy-safe troubleshooting details.

All processing remains local; no accounts, analytics, billing or extra website permissions were added.
The macOS developer-preview companion is unchanged at 1.7.1 and is not included in the store ZIP.

Verification: 108 unit/component tests, type checking, linting, development/store builds and
validators, Chromium smoke suites, and a visible Chrome test of real permission grant/revocation,
capture recovery on an already-open tab, and the actual popup shortcut.

Upload `clipboard-plus-v1.8.0-store.zip` to the existing Chrome Web Store item. This GitHub release
does not submit or automatically update the deployed Chrome Web Store listing.
