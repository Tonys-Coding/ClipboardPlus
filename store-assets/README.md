# Chrome Web Store screenshots

These five 1280×800 PNGs are captured by `npm run assets:store` from the actual Clipboard+ store build running in Chromium. The script seeds representative local demo clips in a temporary browser profile; it does not use anyone's private clipboard history or draw substitute interface components. Each unaltered UI capture is placed on the product's petrol-navy background alongside the official logo and a short use-case caption.

1. `screenshot-1-history.png` — Recent history, category navigation, clip details, and the honest website-access-off state.
2. `screenshot-2-search.png` — A successful content search returning a manual note.
3. `screenshot-3-code-filter.png` — The Code view displaying a real function from Clipboard+'s own `src/lib/clips.ts`.
4. `screenshot-4-smart-snippet.png` — A saved snippet with its actual fill-in dialog and preview.
5. `screenshot-5-privacy-controls.png` — The first-run Capture Controls disclosure and optional website-capture choice.

The first text sample appears on Clipboard+'s own public homepage; the code sample appears in the linked GitHub source. The other clips are clearly representative examples. Website capture remains off in this temporary profile, so the screenshots do not claim permission was granted or that content was automatically captured.
