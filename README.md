# Clipboard+

Clipboard+ is a private, local-first clipboard history for Chrome and macOS. The extension classifies text, links, and recognizable code, and provides favorites, search, editing, and one-click copying; the optional menu-bar companion captures text copied in Discord, Notion, Finder, Chrome, and other applications.

## Development

```bash
npm install
npm run build
```

Load the generated `dist` folder through `chrome://extensions` with **Developer mode → Load unpacked**.

Other useful commands:

```bash
npm run dev
npm run typecheck
npm run lint
npm test
npm run test:e2e
npm run test:native
```

## macOS companion

Install and start universal capture with:

```bash
npm run install:companion
```

This installs two local binaries under `~/Library/Application Support/ClipboardPlus`, registers `com.clipboardplus.native` for Chrome Native Messaging, and starts a `C+` menu-bar LaunchAgent. Reload the unpacked extension afterward.

Use the `C+` menu to pause or resume system-wide capture. To remove the companion while preserving its pending queue, run `zsh scripts/uninstall-macos-companion.sh`; add `--purge` to remove the queue and log as well.

## Privacy and capture boundaries

- All history stays in `chrome.storage.local`; pending native captures briefly stay in `~/Library/Application Support/ClipboardPlus` until Chrome imports and acknowledges them. Clipboard+ has no backend, analytics, or account system.
- The companion monitors the macOS text clipboard locally. It ignores macOS concealed, transient, and autogenerated clipboard types.
- 1Password, Bitwarden, LastPass, KeePassXC, and Keychain Access are excluded by default. Other applications can still place sensitive text on the normal clipboard, so use the `C+` pause control when needed.
- Password fields and fields marked for authentication or payment-card autofill are ignored.
- Without the companion, Chrome internal pages, the Chrome Web Store, browser UI, and desktop applications cannot be captured. The companion sees the resulting system clipboard instead and covers most of those gaps.
- Incognito access is disabled in the manifest.

## Using the extension

- Click a clip to copy it immediately.
- Use the three-dot menu to favorite, edit, or delete it.
- Use **Add clip** for manual text and URLs, or **Save tab** to store the current page.
- On a webpage, right-click selected text or a link and use the dedicated **Save … to Clipboard+** action for a guaranteed capture path.
- Open Settings to pause capture, exclude domains, change the history limit, or clear saved data.

## Capture troubleshooting

Opening the popup checks the page listener and reinjects it when Chrome has left an eligible tab without one. Clipboard+ displays an inline warning only when capture is disabled, excluded, restricted, or unavailable.

If capture is unavailable, verify **Site access → On all sites** in the extension's Chrome settings and refresh the page. Browser-owned surfaces—including the address bar, New Tab, Chrome settings, and the Chrome Web Store—cannot expose copy events to extensions. Native **Copy link address** may also bypass the page copy event; use Clipboard+'s own context-menu link action in that case.
